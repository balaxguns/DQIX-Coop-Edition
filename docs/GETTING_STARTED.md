# Beginner getting started

This repository currently contains **planning and testing documents, not a playable mod**.

1. Get Git for Windows and a source-code editor such as VS Code.
2. Clone this repository to a folder on your Windows PC.
3. Read `PROJECT_SCOPE.md` and `TECHNICAL_PLAN.md`.
4. Read the [DQIX Enhanced upstream README](https://github.com/sackchief/dqix-enhanced) and its [license](https://github.com/sackchief/dqix-enhanced/blob/main/LICENSE) before starting a derivative.
5. Keep your own legally dumped cartridge ROM **outside** this repository. Never upload or share it here.
6. First prove the unmodified upstream builds and launches correctly before modifying the creation process.
7. Record reproducible test outcomes in `TEST_MATRIX.md`.

We will add platform-specific build commands only after the corresponding upstream version and prerequisites are verified.
